Treasure Map Adventure

Students write a sequence of commands to move the avatar to the treasure. Combine REPEAT/WHILE loops and IF/ELSE logic to keep the avatar safe.

Enter your name to run programs and record high scores.
Example commands: MOVE, TURN LEFT, TURN RIGHT, JUMP, PICK TREASURE, REPEAT 3 TIMES, IF PATH AHEAD CLEAR THEN, ELSE, ENDIF, WHILE NOT ON TREASURE DO, ENDWHILE
Conditions you can test: PATH AHEAD CLEAR, PATH AHEAD BLOCKED, ON TREASURE. Prefix with NOT to invert. Need to hop over trouble? Use JUMP to leap straight ahead by one cell without changing direction.
ms per step
Click cells on the map to place obstacles/treasure/start. Default: start=A1 (top-left), treasure=C4, a few obstacles preset.
One shared algorithm. Four fixed levels. Enter your name above and hit Start Challenge to run the exact same program across all maps. Results appear in the Hall of Fame below the board.
